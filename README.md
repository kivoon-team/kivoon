# כיוון | Kivoon

אפליקציית רשת בעברית לחיפוש תפקידי ניהול בתחומי דאטה, אנליטיקה, בינה עסקית ובינה מלאכותית בישראל, עם עדיפות לדרום.

## הגרסה הנוכחית

גרסת ממשק ראשונית של המסך שאחרי התחברות. המשרות הן נתוני הדגמה המבוססים על מחקר מ־5 באוקטובר 2026. אין התחברות אמיתית, עדכון מקורות או ניתוח באמצעות מודל בשלב הזה.

- חיפוש לפי תפקיד, חברה ותחום.
- סינון לפי מיקום, תחום מקצועי ואחריות ניהולית.
- שמירת משרות, הערות אישיות ומעקב אחר שלבי המועמדות.
- חלון פרטי משרה וקישור למקור.
- שמירת העדפות חיפוש במכשיר.
- מידע על חברות עם פעילות בדרום, בנפרד מאימות אפשרות לעבוד שם.
- תצוגה מותאמת למחשב ולנייד, מימין לשמאל.
- תמיכת PWA: מניפסט, אייקונים ושמירת הממשק לשימוש ללא רשת לאחר הביקור הראשון.

כל השמירות מקומיות לדפדפן. הן אינן מסונכרנות בין מכשירים. לא נשלחות מועמדויות אוטומטית.

## הרצה מקומית

נדרשת Node.js בגרסה 22 ומעלה. אין תלויות להתקנה.

```sh
npm start
```

פתחו את http://localhost:4173 בדפדפן. אם הכתובת כבר בשימוש, אפשר להגדיר משתנה סביבה `PORT`.

```sh
npm run check
```

בדיקה זו מאמתת תחביר JavaScript בלבד. היא אינה מחליפה בדיקת התנהגות בדפדפן.

## פרסום והתקנה

הממשק מורכב מקבצים סטטיים. כדי לפרסם אותו יש להגיש את קובצי הממשק משורש אתר מאובטח ב־HTTPS. `server.cjs` הוא שרת תצוגה מקומי; הוא אינו שרת אימות או מקור נתונים.

התקנה נתמכת בדפדפנים מתאימים דרך תפריט הדפדפן או כפתור ההתקנה. התמיכה תלויה בדפדפן. localhost מאפשר בדיקה מקומית של תכונות PWA.

## עקרונות המוצר

- שנות הניסיון המקצועי של המועמד אינן מסנן שפוסל מודעות שדורשות פחות.
- מפרידים בין ניהול עובדים להובלה מקצועית.
- מפרידים בין מיקום המשרה, פעילות החברה בדרום ואפשרות מוכחת לעבוד ממנו.
- מציינים מידע חסר במקום להמציא כישורים או אחוזי התאמה.
- כשל באימות מקור אינו הוכחה שמשרה נסגרה.
- הנתונים לדוגמה אינם הוכחה שמשרה עדיין פתוחה. יש לבדוק את המודעה המקורית.

## אימות הגרסה הראשונית

בוצעה בדיקה בדפדפן של חיפוש, סינון, מצב ללא תוצאות, מועדפים, פרטי משרה, הערות, שינוי סטטוס והעדפות. נבדקו שמירה לאחר טעינה מחדש, תצוגות מחשב ונייד וטעינה ללא חיבור לרשת.
