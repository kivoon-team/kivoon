# כיוון | Kivoon

אפליקציית רשת בעברית לחיפוש תפקידי ניהול בתחומי דאטה, אנליטיקה, בינה עסקית ובינה מלאכותית בישראל, עם עדיפות לדרום.

## הגרסה הנוכחית

גרסת ממשק ראשונית של המסך שאחרי התחברות. משרות מוצגות רק לאחר שהתקבלו בבדיקה עדכנית מלוחות Greenhouse הציבוריים של Pagaya ו־DoiT, וסוננו למיקומים בישראל או לעבודה מרחוק מישראל. התוצאות מייצגות משרות שהופיעו כפתוחות בלוח בזמן הבדיקה; יש לאמת שוב באתר המעסיק לפני פעולה.

- חיפוש לפי תפקיד, חברה ותחום.
- סינון לפי מיקום, תחום מקצועי ואחריות ניהולית.
- שמירת משרות, הערות אישיות ומעקב אחר שלבי המועמדות.
- רענון משרות Greenhouse בזמן טעינה או לפי דרישה, בלי שימוש ברשימה שמורה או בנתוני הדגמה במקרה של כשל.
- קישורי חיפוש חיצוניים ל־LinkedIn ול־GotFriends. התוצאות באתרים אלה אינן מיובאות לאפליקציה.
- חלון פרטי משרה וקישור למקור.
- שמירת העדפות חיפוש במכשיר.
- מידע על חברות עם פעילות בדרום, בנפרד מאימות אפשרות לעבוד שם.
- תצוגה מותאמת למחשב ולנייד, מימין לשמאל.
- תמיכת PWA: מניפסט, אייקונים ושמירת הממשק לשימוש ללא רשת לאחר הביקור הראשון.

כל השמירות מקומיות לדפדפן. הן אינן מסונכרנות בין מכשירים. לא נשלחות מועמדויות אוטומטית.

## הרצה מקומית

נדרשת Node.js בגרסה 22 ומעלה. אין תלויות להתקנה.

```sh
npm start
```

פתחו את http://localhost:4173 בדפדפן. אם הכתובת כבר בשימוש, אפשר להגדיר משתנה סביבה `PORT`.

```sh
npm run check
```

בדיקה זו מאמתת תחביר JavaScript בלבד. היא אינה מחליפה בדיקת התנהגות בדפדפן או אימות זמינות של כל משרה.

## פרסום והתקנה

הפרויקט כולל הגדרות לפריסה ב־Vercel. הפקודה `npm run build` בודקת תחביר ומעתיקה את קובצי הממשק לתיקיית `dist`. פונקציית `api/jobs.js` מספקת את נתוני Greenhouse בפריסה, ו־`server.cjs` מספק את אותו נתיב בסביבה המקומית.

`/api/jobs` קורא רק את ממשק המשרות הציבורי לקריאה של Greenhouse; אין מפתחות API. LinkedIn ו־GotFriends נפתחים לחיפוש ידני באתריהם, ואין בפרויקט איסוף אוטומטי מהם. כאשר לא ניתן לבדוק לוח, המשרות אינן מוצגות.

התקנה נתמכת בדפדפנים מתאימים דרך תפריט הדפדפן או כפתור ההתקנה. התמיכה תלויה בדפדפן. localhost מאפשר בדיקה מקומית של תכונות PWA.

## עקרונות המוצר

- שנות הניסיון המקצועי של המועמד אינן מסנן שפוסל מודעות שדורשות פחות.
- מפרידים בין ניהול עובדים להובלה מקצועית.
- מפרידים בין מיקום המשרה, פעילות החברה בדרום ואפשרות מוכחת לעבוד ממנו.
- מציינים מידע חסר במקום להמציא כישורים או אחוזי התאמה.
- כשל באימות מקור אינו הוכחה שמשרה נסגרה, ולכן כשל מקור מציג מצב שגיאה ולא מודעות קודמות.
- לוח פעיל עשוי להשתנות מיד לאחר בדיקתו; יש לבדוק את המודעה המקורית לפני הגשת מועמדות.

## אימות הגרסה הראשונית

בוצעה בדיקה בדפדפן של חיפוש, סינון, מצב ללא תוצאות, מועדפים, פרטי משרה, הערות, שינוי סטטוס והעדפות. נבדקו שמירה לאחר טעינה מחדש, תצוגות מחשב ונייד וטעינה ללא חיבור לרשת.
